Entry Vault
============

主な機能
- スクリーンショットから名前・建物名・部屋番号をOCR自動入力
- スクリーンショットのSHA-256完全一致とOCR結果による類似登録の検知
- 重複候補から詳細確認・編集・新規登録続行・キャンセルを選択
- 全項目の手入力
- 暗証番号の手入力・マスク表示
- 名前、建物名、部屋番号、暗証番号、メモ、OCR全文の横断検索
- AES-GCM暗号化保存
- WebAuthn対応端末では指紋・顔・Windows Hello・端末PINで解除
- マスターパスワードによる復旧手段を維持
- 15分無操作で自動ロック
- 登録内容の編集・削除
- スクリーンショットの暗号化保存（任意）
- 暗号化バックアップ書き出し・復元
- PWA対応（ホーム画面へ追加可能）

使い方
1. ZIPを展開します。
2. GitHub PagesなどのHTTPS環境へ、フォルダ内のファイルをそのままアップロードします。
3. 初回起動時に8文字以上のマスターパスワードを設定します。
4. 設定画面の「生体・端末認証」から、この端末の認証を登録できます。
5. 「登録」でスクリーンショットを選択します。同じ画像が登録済みの場合はOCR前に候補を表示します。
6. OCRを実行します。名前・建物名・部屋番号が一致する登録がある場合は類似候補を表示します。
7. 候補が出た場合は、登録済み情報を開く・編集する・今回は新規登録を続ける・キャンセルから選択します。
8. 自動入力結果を確認し、暗証番号を手入力して保存します。
9. 「検索」では全項目をまとめて検索できます。

重要
- マスターパスワードを忘れた場合、保存データは復元できません。
- ブラウザデータを消去すると保存内容も消えるため、定期的に設定画面からバックアップしてください。
- OCRは初回のみOCR本体・日本語学習データのダウンロードが必要です。
- 画像や登録内容はOCR処理時も外部サーバーへアップロードされません。
- 画像ハッシュの生成と重複照合も端末内だけで行い、暗証番号は候補画面でマスク表示します。
- 更新前の登録データはそのまま利用できます。保存画像がある既存登録は画像から端末内でハッシュを生成して照合します。
- PWA、Web Crypto、Service Workerのため、HTTPSまたはlocalhostで利用してください。

生体・端末認証について
- WebAuthnに対応するブラウザ・端末で設定できます。新規設定では互換性を優先し、WebAuthnによる本人確認と端末内の非抽出鍵を組み合わせて復号キーを保護します。
- 「設定する」を押すと先に端末認証画面が開き、認証完了後にマスターパスワード確認が表示されます。
- 認証方法は端末側が選択するため、指紋だけに固定されず、顔・Windows Hello・端末PINが表示される場合があります。
- 生体・端末認証の設定はバックアップへ含めません。機種変更や復元後は、マスターパスワードで解除して再設定してください。
- GitHub PagesのプロジェクトURLは同じユーザー名配下で同一オリジンになるため、暗証番号を扱う本番運用では専用サブドメインへの公開を推奨します。
